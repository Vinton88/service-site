# Сайт мастера услуг на Flask

Локальный fullstack-сайт мастера услуг на Python, Flask и SQLite. На главной
странице размещены визитка, ссылки, калькулятор стоимости и форма заявки.
Успешные заявки сохраняются в SQLite и отображаются в защищённом разделе
администратора.

## Требования

- Windows 10 или Windows 11;
- Python 3.10 или новее;
- PowerShell;
- современный браузер.

Сборщик frontend-ресурсов и дополнительные сервисы не требуются.

## 1. Установка Python

1. Откройте страницу [загрузки Python для Windows](https://www.python.org/downloads/windows/).
2. Скачайте актуальную стабильную версию Python 3.10 или новее.
3. Запустите установщик. Если установщик предлагает этот параметр, включите
   **Add Python to PATH**, затем завершите установку.
4. Закройте и снова откройте PowerShell.

Проверьте установку:

```powershell
py --version
```

Если команда `py` недоступна, но работает `python --version`, замените `py` на
`python` в команде создания виртуального окружения ниже.

## 2. Создание виртуального окружения

Откройте PowerShell в корневой папке проекта — там, где находятся `app.py` и
`requirements.txt`. Затем выполните:

```powershell
py -m venv .venv
```

## 3. Активация окружения в PowerShell

```powershell
.\.venv\Scripts\Activate.ps1
```

Если PowerShell сообщает, что выполнение сценариев запрещено, разрешите его
только для текущего окна PowerShell и повторите активацию:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

После активации в начале строки PowerShell появится `(.venv)`.

## 4. Установка зависимостей

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 5. Настройка доступа администратора

Задайте логин и пароль в текущем окне PowerShell:

```powershell
$env:ADMIN_USERNAME = "my_admin"
$env:ADMIN_PASSWORD = "replace-with-a-long-random-password"
```

Переменные действуют только в текущем сеансе PowerShell. При запуске приложения
из нового окна задайте их снова.

Если переменные не заданы, приложение использует демонстрационные значения:

- логин: `demo_admin`;
- пароль: `ChangeMe-LocalDemo-9f3!`.

Демонстрационные данные предназначены только для локальной проверки. Не
используйте их для публично доступного приложения.

## 6. Запуск

В активированном виртуальном окружении выполните:

```powershell
python app.py
```

Остановить сервер можно сочетанием `Ctrl+C`.

## 7. Адрес главной страницы

После запуска откройте:

[http://127.0.0.1:5000/](http://127.0.0.1:5000/)

## 8. Адрес административной страницы

Список заявок доступен по адресу:

[http://127.0.0.1:5000/admin](http://127.0.0.1:5000/admin)

Браузер запросит логин и пароль через HTTP Basic Authentication. Используйте
значения `ADMIN_USERNAME` и `ADMIN_PASSWORD`, заданные перед запуском, либо
демонстрационные значения по умолчанию.

> HTTP Basic Authentication без HTTPS не шифрует учётные данные и подходит
> здесь только для локального демонстрационного проекта. Для размещения в
> интернете необходимы HTTPS, отдельные надёжные учётные данные и
> production-ready механизм аутентификации.

## 9. Расположение базы данных

SQLite-база создаётся автоматически при первом запуске:

```text
data/requests.db
```

В ней находится таблица `requests` с сохранёнными заявками. Файл базы исключён
из Git, а пустая папка `data` сохраняется в репозитории с помощью
`data/.gitkeep`.

## Быстрый повторный запуск

После первой установки для следующего локального запуска достаточно открыть
PowerShell в папке проекта и выполнить:

```powershell
.\.venv\Scripts\Activate.ps1
$env:ADMIN_USERNAME = "my_admin"
$env:ADMIN_PASSWORD = "replace-with-a-long-random-password"
python app.py
```

## Автоматическая проверка

После установки зависимостей весь набор серверных тестов запускается одной
командой:

```powershell
python -m unittest discover -s tests -v
```

Тесты используют отдельные временные базы данных и не меняют
`data/requests.db`.
